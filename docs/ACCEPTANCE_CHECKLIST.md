# Foundation Acceptance Checklist

## Repository
- [ ] README explains scope and current limitations.
- [ ] Product, architecture, UX, privacy, model evaluation, and roadmap docs exist.
- [ ] Open decisions are recorded.
- [ ] Antigravity handoff is actionable.
- [ ] No user audio or model weights are tracked.
- [ ] No credentials or real environment values are committed.

## Scaffold
- [ ] Python package imports.
- [ ] Health endpoint returns a truthful status.
- [ ] Capabilities endpoint does not claim speech generation is available.
- [ ] Tests pass in a supported Python environment.
- [ ] Ruff passes.

## Discovery
- [ ] Target laptop hardware is recorded.
- [ ] Model code and weight licenses are checked.
- [ ] Urdu quality is evaluated with listening samples.
- [ ] Existing two-minute WAV suitability is tested.
- [ ] Offline behavior and hardware cost are documented.
- [ ] Model choice is approved before integration.
